# Auto škola Prioritet, sajt

Statican sajt, dve strane.

- `index.html` pocetna strana
- `pitanja.html` pitanja i rezervacija termina
- `support.js` runtime koji strane koriste, mora da ostane u istom folderu
- `.nojekyll` da GitHub Pages ne dira fajlove

## Hostovanje na GitHub Pages

1. Napravi repozitorijum i ubaci sadrzaj ovog foldera u koren (index.html mora da bude u korenu).
2. U repozitorijumu idi na Settings, pa Pages.
3. Pod Source izaberi Deploy from a branch, branch `main`, folder `/ (root)`, pa Save.
4. Za minut sajt je na adresi https://<korisnik>.github.io/<repo>/
